# Data Description

## Source
All datasets are derived from hydraulic model outputs prepared for dam breach and release analysis of Kurnur (BORI) Dam.

## Time Resolution
- Uniform time-step (typically 5 minutes)

## Parameters
- Headwater Elevation (m)
- Tailwater Elevation (m)
- Total Discharge (m³/s)
- Breach Discharge (m³/s)
- Breach Width (m)
- Breach Velocity (m/s)

## Notes
- Raw data files are preserved without modification
- Each Excel file corresponds to a single failure or operation scenario
